# Virtual Assistant Portfolio

Responsive portfolio website inspired by the supplied reference image.

## Files
- `index.html` - page structure and portfolio content
- `style.css` - responsive styling and layout
- `script.js` - mobile menu, theme toggle, and project expansion
- `assets/` - place your own profile photo, CV, and images here

## Customize before publishing
1. Replace Selen Wanjiku and all contact/profile links with your real details.
2. Replace the `SW` avatar placeholder with your photo.
3. Replace the CV button destination with your actual CV file.
4. Add genuine project samples and adjust skill levels to reflect your experience.
5. Update all example project metrics so they only make claims you can support.

## Run locally
Open `index.html` in a browser. For best results, use a local development server.

## Publish with GitHub Pages
In the repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
